# Запуск бота на Railway (бесплатно/дёшево)

Railway — облачная платформа (серверы в США), идеально подходит: вне
блокировок РКН, деплой из GitHub, Docker-поддержка.

> ⚠️ Про бесплатность: у Railway нет постоянного бесплатного тарифа.
> Новым пользователям дают пробный кредит (~$5), дальше — план Hobby
> ($5/мес). Бот лёгкий, поэтому пробного кредита хватает на пару месяцев.
> Полностью бесплатная альтернатива — Oracle Cloud «Always Free» (см. внизу).

## Шаг 1. Загрузите код в GitHub

1. Создайте репозиторий на [github.com](https://github.com/new) (можно Private).
2. Загрузите туда содержимое папки `aroma_menu_bot` (кроме `.env` — он в `.gitignore`).

Проще всего через GitHub Desktop или командой:
```bash
git init
git add .
git commit -m "aroma menu bot"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/aroma-menu-bot.git
git push -u origin main
```

## Шаг 2. Деплой на Railway

1. Зайдите на [railway.com](https://railway.com) → **Login with GitHub**.
2. Нажмите **New Project** → **Deploy from GitHub repo** → выберите свой репозиторий.
3. Railway сам найдёт `Dockerfile` и соберёт образ.
4. Добавьте переменные окружения (вкладка **Variables**):
   - `BOT_TOKEN` = ваш токен от BotFather
   - (опционально) `YANDEX_URL`, `GOOGLE_SHEET_ID`, `SKIP_SHEETS` — уже прописаны в коде по умолчанию
5. Railway сам задаст `PORT` и поднимет сервис — бот начнёт работать.

Проверить логи: вкладка **Deployments** → **View Logs**.

## Шаг 3. Обновление меню/кода

- Меню бот сам перечитывает раз в час (и рассылает уведомления).
- Чтобы обновить код: сделайте `git push` — Railway пересоберёт и перезапустит автоматически.

## Примечания

- **Список пользователей** для рассылки (`data/users.json`) хранится в
  контейнере и сбрасывается при пересборке. Это не критично: пользователи
  снова попадут в список, когда откроют бота.
- Health-сервер уже встроен: бот слушает `$PORT`, поэтому Railway считает
  сервис живым и не перезапускает его.

## Полностью бесплатно: Oracle Cloud «Always Free»

Если нужен именно бесплатный вариант без ограничений по времени:

1. Зарегистрируйтесь на [oracle.com/cloud/free](https://www.oracle.com/cloud/free/).
2. Создайте VM (ARM, Always Free — 4 CPU / 24 ГБ RAM, бесплатно навсегда).
3. Установите Docker и запустите бота по инструкции из `DEPLOY.md`.
