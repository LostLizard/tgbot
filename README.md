# Телеграм-бот «Техническое меню AROMA»

Бот для персонала ресторана AROMA. Показывает полное техническое меню:
состав блюд, способ приготовления, подачу и аллергены.

Данные берутся из Excel-файла, который лежит в двух местах:
1. **Яндекс.Диск** (основной источник);
2. **Google Sheets** (резерв — используется, если Яндекс недоступен).

## Возможности

- `/start`, `/menu` — список разделов меню (категории);
- навигация по категориям → блюдам → полное описание блюда;
- `/search <текст>` — поиск блюда по названию или описанию;
- `/refresh` — принудительно перечитать Excel;
- меню кэшируется в памяти и перечитывается раз в час (настраивается).

## Установка

```bash
cd aroma_menu_bot
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

pip install -r requirements.txt
```

## Настройка

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env` и вставьте токен:

```bash
copy .env.example .env          # Windows
# cp .env.example .env          # Linux/macOS
```

В `.env` можно оставить ссылки по умолчанию или поменять на свои.

## Запуск

```bash
python bot.py
```

## Как устроена загрузка меню

- **Яндекс.Диск.** Файл размещён с ограничением «просмотр без скачивания»,
  поэтому обычный API отдаёт пустую ссылку. Бот использует тот же механизм,
  что и сам просмотрщик: берёт WOPI-токен из HTML страницы
  `docs.yandex.ru/view/d/...` и скачивает исходный `xlsx` через
  `office-online` WOPI-эндпоинт. Токен короткоживущий, но каждый раз
  запрашивается заново.
- **Google Sheets.** Скачивается напрямую через `/export?format=xlsx`.

Если Яндекс отдаёт ошибку (нет доступа, токен не найден, сеть) — бот
автоматически переключается на Google.

## Структура файла меню

- каждая вкладка Excel = категория («Пицца», «Супы», «Горячее», …);
- колонка A — заголовки подразделов и примечания;
- колонка B — блюда: первая строка = название, дальше = описание.

Вкладка `Утро` — это сводная (устаревшая) копия всего меню, поэтому по
умолчанию она пропускается. Управляется параметром `SKIP_SHEETS`.
